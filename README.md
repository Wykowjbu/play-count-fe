# Play Count FE

Frontend for the Play Count web app, built with React and Vite.

## Published Site

https://wykowjbu.github.io/play-count-fe/

## Development

Install dependencies and run the app locally:

```sh
pnpm install
pnpm dev
```

Build for production:

```sh
pnpm build
```

## GitHub Pages

This project is configured for GitHub Pages with Vite `base` set to `/play-count-fe/`.

Deployments run from `.github/workflows/deploy-pages.yml` after pushes to `master`.
